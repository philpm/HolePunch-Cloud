# Cloud 迭代计划

[English](../ROADMAP.md) | 简体中文 · [文档目录](README.md)

## 当前迭代：统一运营者体验

固定共享核心、英文原文文档/诊断、可见且持久的语言切换、管理员设置、按角色组织的侧栏，以及原生/源码/Compose 部署摘要。保留已有租户隔离和隧道分配，提供旧未标记服务端迁移到 Cloud schema 4 的验证路径，包括备份回滚。

## 小规模试用准备

开放注册前配置并验证生产 SMTP。邀请少量用户试用，检查邀请与密码重置、异机备份恢复、进程健康和错误日志。收集易用性反馈，不增加累计传输量配额。

## 分发与运维强化

CI 通过后自动化可复现公开产物与镜像发布，验证实际 Linux systemd、Compose 部署和支持的桌面系统，将升级演练与恢复练习纳入发布验收，根据实测需要扩展可观测性。

## 后续路由

单节点稳定后再设计节点身份、区域/线路选择、调度与故障切换。目前不宣称自动全球最优路由。计费、累计流量配额和独立 Cloud 桌面分支不在当前范围内。
