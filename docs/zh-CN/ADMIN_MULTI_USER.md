# Cloud 管理员指南

[English](../ADMIN_MULTI_USER.md) | 简体中文 · [文档目录](README.md)

使用邮箱和密码登录，可通过顶部语言选择切换英文/简体中文。侧栏分别提供概览、客户端、隧道、带宽分配和账户设置；管理员还可查看用户管理、默认策略、本机网站、节点设置、审计日志和设置向导。

## 首次设置

新管理员进入四步设置向导：确认账户、按需改密、设置公网控制主机和平台域名后缀、执行本地服务检查，然后保存并添加客户端。切换语言会保留表单草稿，已有部署可重新打开且不重置数据。

Web 隧道需要把 `*.t.example.com` 解析到服务器，并配置 `t.example.com` 后缀。Cloud 用户可以在后缀内选名称或随机分配。普通 HTTP CDN 不能承载 Noise 控制连接，`HP_PUBLIC_ADDR` 应使用公网 IP 或仅 DNS 解析的域名。

## 用户与注册

在部署环境配置 SMTP 并重启后，才能在**默认策略**开放注册。注册账户是普通成员，创建资源前需验证邮箱。**用户管理**可发送设置密码的邀请、重发邀请、修改角色/状态和管理用户资源。邮件投递状态会记录，成功排队不代表邮件已经进入收件箱。

普通用户默认额度为 1 个客户端、2 条隧道和 1 Mbps。个别用户留空表示继承默认值，0 表示无容量。不能删除最后一个有效管理员。冻结账户会断开访问；删除移除资料和资源，域名在冷却期后释放。破坏性修改需检查确认对话框。

## 带宽

每条隧道都有带宽分配，禁用后仍占用额度。用户的总分配不能超过其额度。限速聚合双向与所有连接，1 Mbps 为 1,000,000 bit/s，0 禁用隧道。可在**带宽分配**原子调整多条隧道，或在**用户管理**同时调整用户额度与隧道分配。默认值降低到已有分配之下会被拒绝，需先调整受影响用户。运行时限速变化会断开现有连接。没有累计、每日或每月流量配额。

## 客户端

创建设备取得一次性接入码，在用户机器运行 `holepunch-client connect --server https://panel.example.com` 并按提示输入。在控制台设置本地地址、协议、端口和域名。桌面应用只是状态/日志的可选辅助，不是必需。每台设备使用独立身份，丢失设备应撤销。

## 已有网站共存

**本机网站**通过受管入口把批准的域名路由到回环应用，不要手工编辑 Caddy 生成的路由。**节点设置**管理服务端地址和诊断。公网端口、防火墙转发和 DNS 仍需部署配置，设置向导不会修改云厂商防火墙。
