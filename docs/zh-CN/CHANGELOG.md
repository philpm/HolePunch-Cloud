# 更新记录

[English](../../CHANGELOG.md) | 简体中文 · [文档目录](README.md)

## 未发布 — CI 与依赖维护

- 更新共享核心和 Cloud 锁文件，包含加密兼容性修复及 TLS/QUIC 漏洞补丁。
- CI 和发布构建审计 Cloud 依赖；公告服务持续不可用时明确失败。
- 更新 Actions、合并依赖 PR、避免重复 CI，并保留已验证的编译器基线。

## 未发布 — 双语文档

- 围绕特性、完整快速开始、配置和贡献资源重写两个首页。
- 增加简体中文首页与配套用户、开发和社区指南，检查对应英文源版本。
- 原生归档包含翻译文档和项目图标。

## 未发布 — 开源维护

- 支持校验和验证的公开 Cloud 归档下载。
- 两个产品及包元数据统一 Apache-2.0。
- 发布贡献、支持、行为准则、国际化和维护指南。
- 整合产品文档，内部验收日记移出公开历史。
- CI 检查仓库规范和文档链接，保留中英文国际化验证。

## 未发布 — Cloud 体验统一

- 固定英文原文共享核心与控制台，支持持久语言选择。
- 开放管理员设置，不向成员暴露，不改变租户额度。
- 复用交互原生、源码和 Compose 部署工具，含私密初始访问摘要和版本类型校验。
- Cloud 诊断与邮件内容改为英文，控制台错误支持翻译。
- 记录已有原生部署从 schema 2 迁移、备份与回滚的方法。
