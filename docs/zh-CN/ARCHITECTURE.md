# Cloud 架构

[English](../ARCHITECTURE.md) | 简体中文 · [文档目录](README.md)

Cloud 是链接到固定 `holepunch-server-core` 的小型 Rust 应用。路由增加邮箱注册/验证/重置、SMTP 投递、管理员用户/邀请和默认策略。共享核心提供会话、所有权校验、客户端/隧道、接入、配置同步、本机网站、设置和控制台。SQLite schema 4 保存元数据，rathole 承载 Noise 加密设备连接，Caddy 路由 HTTPS。

每条 Cloud 隧道经过进程内网关，所有连接和双向流量共享一个令牌桶。用户额度在配置时限制分配，数据平面执行隧道限速；禁用仍保留分配，不实现累计流量计费。

控制台按角色展示侧栏，并有完整中英文词条。首次设置仅管理员可用，写操作要求会话和 CSRF，设备令牌只用于设备 API。密码哈希在异步请求工作线程之外，通过有并发上限的工作池运行。

原生、源码、Compose 使用相同 Cloud 二进制。初始凭据本地生成，设置 API 不返回秘密。已有实例保留设置状态和配置，见[共享架构](../../vendor/holepunch/docs/zh-CN/ARCHITECTURE.md)和[部署](DEPLOYMENT.md)。

## 租户隔离与分配设计

`client_owners` 记录设备所属用户，隧道继承设备所有权。会话认证与 CSRF 保护浏览器写操作，资源代管要求有效管理员；普通成员不能使用他人设备 ID 或读取其资源。设备以短期一次性码接入并保留独立限定权限令牌。

`user_limits` 保存可空覆盖值，设置表保存默认客户端/隧道/带宽额度。配置事务验证隧道限速总和不超过解析后的用户额度。降低默认值先验证全部受影响用户，个别用户修改可原子重分配隧道。0 带宽禁用，禁用仍保留分配。

`tunnel_limits` 分配内部后端端口与速率。公网连接经共享令牌桶网关转发，重新配置会在更改监听/速率前断开旧会话。数量与分配是配置数据，不是累计流量测量。

邮件验证凭据 30 分钟到期，哈希保存；设备接入码 10 分钟到期且一次性。密码使用 Argon2 和有界后台计算。邮件使用 TLS，本地发件箱仅用于开发，生产默认关闭注册。

设置是共享的管理员功能，不暴露初始化秘密。原子更新保留租户策略；改密验证当前密码并撤销会话。已有数据库跳过自动引导，但侧栏仍有手动入口，见 [API](API.md) 和[迁移回滚](DEPLOYMENT.md)。
