# HolePunch Cloud 产品概览

[English](../OVERVIEW.md) | 简体中文 · [文档目录](README.md)

## 产品与用户

Cloud 是采用 Apache-2.0 的多用户隧道平台，供运营者部署自己的服务。Self-hosted 面向使用自己服务器和域名、希望默认不限速的用户。Cloud 共享转发核心、API 基础、CLI 和控制台，增加用户、邮件身份与资源策略。目前单节点，全球路由属于后续工作。

## 使用要求

- 邮箱/密码登录，可选邮箱注册和验证，新账户为普通成员。
- 管理员邀请/管理用户，设置默认和个别额度；默认 1 客户端、2 隧道、1 Mbps。
- 每条隧道分配速率，用户总分配不超过额度，修改原子完成。不做累计流量统计、计费或传输量配额。
- 设备以一条 CLI connect 命令和一次性接入码接入，隧道设置全部在 Web 控制台，桌面可选。
- 按角色和功能组织侧栏，保护草稿，提供显式中英文切换。
- 所有部署方式说明浏览器访问和初始凭据；新管理员获得设置向导，已有部署保留数据并可重新设置。
- 原生安装、源码构建和 Linux Compose 使用同一应用，并保留共存网站配置。

## 发布验收

验证用户隔离、认证/CSRF、额度、限速、CLI 接入、TCP/UDP/HTTPS、语言切换和设置。用生产备份副本演练迁移/回滚，部署后检查公网端点。本地就绪不能证明 DNS、SMTP 或远端应用可用。
