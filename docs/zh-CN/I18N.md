# 国际化

[English](../I18N.md) | 简体中文 · [文档目录](README.md)

Cloud 复用 HolePunch 的离线国际化运行时与词条。默认英文（`en`），支持简体中文（`zh-CN`），登录前后都有可见选择器。偏好按浏览器保存，切换必须保留路由、未保存表单、打开的对话框、无障碍标签和用户内容。

权威源是 HolePunch 仓库的 `web/locales/en.json` 与 `web/locales/zh-CN.json`。修改前阅读[共享国际化指南](../../vendor/holepunch/docs/zh-CN/I18N.md)，在上游编辑后执行：

```sh
python3 scripts/sync-i18n.py
python3 scripts/sync-i18n.py --check
node --test tests/i18n.test.cjs
```

发布共享提交，更新 Cloud 子模块，再在这里验证：

```sh
python3 vendor/holepunch/scripts/sync-i18n.py --check
node --test vendor/holepunch/tests/i18n.test.cjs
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

Cloud 部署测试检查浏览器可见服务端诊断是否具有共享词条。API 字段、CLI 命令、原始日志、资源名称和邮箱地址不随语言变化。API 诊断与事务邮件目前使用英文，尚未实现邮件语言选择。增加浏览器语言时，需先在共享运行时和桌面中补全键/占位符及选择器。

在两种语言下验证管理员/成员导航、策略表单、邀请、密码重置、设置、验证错误、移动布局和草稿保留。不要提交含凭据或真实租户数据的截图。

## 文档翻译

`README.md` 是英文首页，`README-zh.md` 是简体中文首页。其他译文位于 `docs/zh-CN/`，回链英文与中文目录。英文仍是规范参考，Apache 许可证原文不变。

示例、命令、API 路径、环境变量和代码注释与英文保持一致，翻译说明、标题和表格。行为变化时同步更新两种语言。每篇译文用 `translation-source` HTML 注释记录仓库相对原文路径与 SHA-256 内容版本。审阅译文后，用 `sha256sum SOURCE`（Linux）或 `shasum -a 256 SOURCE`（macOS）更新摘要。仓库检查拒绝过期版本，仅改摘要不算翻译更新。
